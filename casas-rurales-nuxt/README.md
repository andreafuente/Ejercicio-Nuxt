# Casas Rurales – Nuxt 4

## Funcionalidades

- Listado de casas rurales con imágenes e información básica.
- Búsqueda por nombre o ubicación mediante `ref()` y `computed()`.
- Página de detalle de cada alojamiento con características, opiniones y botón de reserva.
- Diseño responsive.
- Componentes reutilizables y layout compartido para la cabecera.
- Optimización de imágenes mediante `@nuxt/image` y el componente `NuxtImg`.


## Experimentos

- Implementación de algunas características de accesibilidad.
- Estrellas en las reseñas con alternativa textual accesible.
- Formato de fechas.
- Uso de la reactividad de Vue 3 mediante `ref()`, `computed()` y `v-model`.
- Separación de componentes, layouts y estilos globales y locales mediante CSS `scoped`.
